# Use Case 81: Combined distillation fix — on-policy + β-floor + extended PPO with an altitude-hold reward

## Summary
UC-80 showed that no single distillation lever — on-policy DAgger relabelling, a gentler β schedule, or a short (6e6-step) PPO fine-tune — lifts the UC-77 MLP student off 0% held-out `macro_completion` at the 1.8e7-step budget. Two diagnostics from UC-80 shape this follow-up: (a) the gentler β-floor (sustained teacher correction) cut out-of-bounds 43.5%→19.4% but the drone then **sinks into the floor** (held-out floor outcome 18.5%→48.8%, Infinity 81%), i.e. the unsolved skill is **altitude/stability control**, not navigation; (b) the PPO fine-tune's reward was still climbing at the end of its 6e6 steps, so its 0% was **undertraining**, not failure. UC-81 therefore combines the levers and removes those two limits: it runs an ablation of (1) a **combined-imitation** variant that applies on-policy relabelling *and* the β-floor together (student-driven execution that still receives teacher correction on student-visited states), and (2) a **combined+PPO** variant that adds a much longer PPO fine-tune (~3e7 steps) against the env reward **augmented with an opt-in altitude-hold / floor-clearance shaping term** aimed squarely at the floor-sinking failure, versus (3) a **baseline** (current distillation). Scope stays MLP-student on the obstacle-free `student-liftoff-open` config, reusing the UC-77/79/80 held-out + Infinity-Loop evaluation (32 episodes, seed 1234, obstacles none, exact + noise, outcome breakdown), a resumable back-to-back driver, and a comparison table + recommendation in `docs/experiments/`. It runs in-sandbox on the RTX A3000 (no Liftoff). Success = at least one variant reaches **≥5% held-out `macro_completion` (noise)**; if none do, this is the decisive signal to pivot away from distillation-tuning (see AC8).

## Acceptance Criteria
1. **Opt-in altitude-hold / floor-clearance reward shaping term**, added to the env reward (the `RewardConfig` path the student env already uses), gated by a new config weight that **defaults to 0 / off** so the baseline reward — and therefore UC-77/79/80 behaviour — is **byte-identical** when unset (config.yaml snapshot, obs, sidecar unchanged; existing tests pass). The term rewards maintaining safe clearance above the floor / a target altitude band and/or penalises descending into the floor; its exact form is the dev-team analyst's to design and document.
2. A **combined-imitation** mode that enables on-policy relabelling (`distill.on_policy_relabel`, from UC-80) together with the β-floor schedule (`beta_end`/`beta_over`, from UC-80) in one run. This should be achievable as a config combination of existing fields — no new execution code beyond what UC-80 added — and a test confirms both levers are active together.
3. A **combined+PPO** mode that runs the combined-imitation setup followed by an **extended PPO fine-tune** (`finetune.steps` ≈ 3e7, materially larger than UC-80's 6e6) optimising the env reward **including** the AC1 shaping term. The PPO path and the shaping term's inclusion in the optimised reward are covered by a test.
4. **Ablation runs**: baseline + combined-imitation + combined+PPO (3 runs), all MLP-student on `student-liftoff-open` (obstacles none), evaluated with the UC-77/79/80 `final_report`: held-out `macro_completion` and Infinity-Loop completion, each exact and noise, plus the outcome breakdown (floor/collision/out-of-bounds/gate_lost/timeout), 32 episodes, seed 1234. Budgets are documented; the combined+PPO run's larger total budget (imitation + ~3e7 PPO) is stated explicitly (equal-budget is relaxed here deliberately, because UC-80 proved the short-PPO equal-budget arm undertrains — document this rather than hiding it).
5. A **resumable, unattended driver** (e.g. `scripts/uc81_combined_fix.sh`) runs the 3 runs back-to-back; a reboot resumes the interrupted run rather than restarting the sequence. Runnable on any CUDA machine with no Liftoff, artifacts documented (teacher `teacher_it1374`, noise model, track cache).
6. `docs/experiments/uc81-combined-distillation-fix.md` contains **one comparison table** — rows: teacher, baseline, the two variants, and the UC-77 / UC-79 (`teacher_full`) / UC-80 (best) references; columns: the AC4 metrics — and ends with a **recommendation**.
7. **Unit tests** cover: AC1 shaping-term default-off byte-identity + the term's wiring into the reward when enabled; AC2 combined-imitation (both levers active); AC3 extended-PPO reward includes the shaping term; and a CPU 1-iteration smoke train for the combined and combined+PPO paths.
8. **Success / pivot**: if at least one variant reaches **≥5% held-out (noise)**, record it as the distillation fix (and the follow-up: apply to the K1 connectome actor). **If neither variant clears 5%**, the doc records the negative result and states the project decision to **pivot to obstacle detection with the 70-input connectome model** (the UC-73 / UC-78 vision line) rather than continue tuning distillation — this UC is the agreed last distillation attempt before that pivot.

## Potential Pitfalls & Open Questions
- **Risk** — even the combined + extended-PPO + shaped-reward run may stay at 0%. That is an acceptable, informative outcome (AC8 pivot branch); the doc must not force a number.
- **Risk** — a badly scaled altitude-hold shaping term can reward-hack (hover high, never race) or destabilise PPO. The analyst must scale it small relative to gate/finish reward and the dev-team should sanity-check the reward curve; keep it opt-in and off by default.
- **Assumption** — on-policy + β-floor compose cleanly as a config combination (UC-80 added `on_policy_relabel`; β is pre-existing). If the on-policy execution path ignores β entirely (UC-80 made execution student-driven when the flag is on), then "β-floor + on-policy" may need the execution to still blend in teacher correction — the analyst must check and, if needed, propose the minimal change so the β-floor actually applies under on-policy.
- **Assumption** — ~3e7 PPO steps is enough to see movement given UC-80's reward was still rising at 6e6; if still clearly rising at 3e7, note it and the budget may need to grow again (but AC8's pivot likely triggers first).
- **Edge case** — the shaping term must not leak into the deployed/default reward or the UC-77/79/80 configs; it is UC-81-opt-in only.
