# Procedural random courses — the K1 connectome generalizing across layouts

Twelve deterministic recordings of the real K1 connectome (25,627 neurons, ~3.86M synapses, real
MaleCNS weights) flying **a different procedurally-generated course every episode** — not a memorized
track. **96% deterministic completion** across the random-course pool, genuinely flying (not cheating).

## What's random (per episode)

- **circular loop**, **5–10 rotated gates** (each gate oriented to its travel direction),
- **varied gate heights** (ground level to ~2 m),
- **per-gate apertures 0.75–1.5 m** (5–10× drone width),
- **≥1 chicane**, gate spacing 1–5 m, **start on the ground** (takeoff),
- **occlusion-aware next-gate lookahead** fed to the readout.

## Audit (deterministic, 192 random courses) — not just the metric

| Check | Result |
|---|---|
| Completion | **96%** (185/192) |
| Gate passes / episode | 6.8 (threads most gates) |
| Hovering? | **No** — mean speed 2.75 m/s, tilt 21° (genuinely flying) |
| Obstacle barging? | n/a (this tier has **no obstacles** — see scope) |

Checked with `verify_proc.py` (per the "don't trust the metric, check the flights" rule): it flies fast
and threads gates, it does not hover or exploit the completion signal.

## Scope (honest)

This is the **obstacle-free tier**: random **gate** courses, **1 lap**, apertures ≥ 5× drone width.
It isolates the hard part that *is* solved — **generalizing across randomized gate layouts/heights/
orientations**. The **full vision is not yet reached**: with obstacles + 2–3 laps + tight (3× ) apertures,
the deterministic policy only completes ~16% and ~14% of those completions *barge* through an obstacle
(the non-terminal nudge gets exploited). That harder tier remains WIP — next step is re-adding obstacles
via the off-path→on-path curriculum that gave clean evasion in `obstacle-lap-flight`.

## Architecture

Augmented frozen-K1 reservoir (`reservoir_aug.py`), warm-started from `figure8-chicane-flight`, trained
with a difficulty curriculum (easy→hard pool) + a precision curriculum (generous pass radius → true
aperture) + exploration annealing. Env `gates_proc_env.py` (per-episode courses from a difficulty-sorted
pool of 1024, generated by `course_gen.py`). Trainer: `PROC_TRACTABLE=1 PROC_NO_OBS=1 train_aug_course.py
proc`. `model_readout.pt` (~640 KB) reload-verified at 96%.

Each `episode_<n>.json` stores all 25,627 neuron activations per frame + action + position + target gate
+ anatomical metadata, and that episode's own random gate layout (so the app draws the exact course flown).
